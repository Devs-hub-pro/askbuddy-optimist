# Contracts Guardrails（A 主线守护）

适用范围：B/C/D 所有端侧仓位  
目标：防止端侧私自扩展后端语义，降低多端并行冲突。

---

## 1. 禁止项

1. 端侧新增后端字段语义（同名不同义也算）
2. 端侧新增状态机值
3. 端侧新增 target_type/item_type 值
4. 端侧新增非白名单 RPC 主路径

---

## 2. 允许项

1. UI 展示字段组合
2. 前端本地派生字段（不回写后端）
3. 在白名单字段内做兼容映射

---

## 3. 冲突处理

冲突提报与仲裁统一按：

- `docs/conflict-resolution-process.md`

未仲裁通过前，不得合并端侧语义变更。
